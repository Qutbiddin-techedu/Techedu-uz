# TechEdu.uz — Virtual Engineering Laboratory Platform

A modern web-based virtual laboratory platform for engineering education. TechEdu.uz provides interactive simulations and calculators for students across three education levels: higher education, technical colleges, and secondary schools.

**Live demo:** [techedu.uz](https://techedu.uz)

## About the Project

TechEdu.uz is developed as part of a PhD research project at Tashkent State Technical University (TSTU), Department of Electrical Machines and Drives Engineering. The platform addresses a critical problem in engineering education across Uzbekistan: limited access to expensive laboratory equipment.

**Scientific foundation:** The platform is based on intelligent control systems for induction electrotechnological devices, using Digital Twin and ANFIS (Adaptive Neuro-Fuzzy Inference System) approaches.

## Features

- **Multi-level Curriculum**: Content tailored for universities, technical colleges, and schools
- **Interactive Modules**:
  - Electrical Technology Fundamentals
  - Electrical Engineering Basics
  - Electronics Foundations
  - Electrical Machines
  - Physics and Astronomy (coming soon)
- **Advanced Calculators**:
  - Skin Effect depth calculations
  - Power consumption analysis
  - Inductor parameter computations
  - 2D thermal simulations for induction heating
- **Real-time Simulations**: Animated 2D cross-section visualization with temperature distribution modeling
- **Multilingual Support**: Uzbek, Russian, and English interfaces
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Google Analytics 4** integration for user tracking

## Getting Started

No build process required. Simply clone the repository and open `index.html` in a modern web browser.

```bash
git clone https://github.com/Qutbiddin-techedu/Techedu-uz.git
cd Techedu-uz
# Open index.html in browser
```
